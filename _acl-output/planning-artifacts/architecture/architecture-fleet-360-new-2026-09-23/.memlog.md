- (direction) Coaching path selected. Run folder: architecture-fleet-360-new-2026-09-23. Inputs: approved PRD, UX DESIGN, brownfield Vite+React 19 starter.
- (decision) Paradigm: Feature-sliced architecture. Code organized by vertical feature slices (login, landing, devices, shell) with shared entities and shared UI primitives. Prevents independent builders from choosing incompatible folder ownership and cross-feature coupling patterns.
- (direction) User prefers Zustand for state management (over TanStack Query recommendation). Pending: clarify client-only vs server-state ownership in Zustand.
- (decision) State: Zustand owns ALL application state — client UI state AND server-fetched data. Domain stores (useAuthStore, useDeviceStore, etc.) encapsulate fetch, polling, loading, error, and cache. Shared api/ adapter layer handles REST calls and DTO mapping; features never call fetch directly. Prevents split-brain between UI state library and server cache library, and prevents fetch logic leaking into components.
- (decision) Phase 1 data source: mock data only — no live REST backend initially. MSW (Mock Service Worker) intercepts same api/ adapter URLs the real backend will use. Swapping to production = replace MSW handlers, not feature code. Prevents mock fetch scattered in components or feature-specific fixtures.
- (decision) Routing: React Router v7 with layout-level AppShell route and ProtectedRoute guard reading useAuthStore. Public: /login. Protected: /, /devices, /devices/:id/*, stub routes. Prevents ad-hoc conditional rendering for nav vs page access.
- (decision) Shared entities: canonical TypeScript types in entities/ (Device, Site, Session, User). api/ adapters map mock/API DTOs to entities; Zustand stores hold entities never raw DTOs. Prevents list vs detail tab shape drift.
- (assumption) Device polling (30s) implemented inside useDeviceStore via setInterval calling api/devices; same interval whether mock or live.
- (decision) Auth session: localStorage key fleet360:session stores token JSON; useAuthStore hydrates on boot. Logout clears store + localStorage. ProtectedRoute redirects unauthenticated users to /login. [ADOPTED per user]
- (decision) Styling: UX DESIGN.md tokens exported as CSS custom properties in shared/styles/tokens.css. Features consume tokens via CSS modules or class names — no hardcoded hex in feature code. Prevents visual drift from approved design system.
- (decision) Deployment: Static SPA built with Vite, hosted on Vercel. MSW active in dev/preview; production build ships with MSW until real API available (env flag VITE_USE_MSW). API base URL via VITE_API_BASE_URL. Prevents environment-specific hardcoding.
- (decision) Error envelope: api/ adapters throw ApiError { code, message, status }; stores catch and set error string; UI shows user-friendly message only (NFR-5). No raw errors in components. Prevents inconsistent error UX across features.
